# MongoDB Scripts

## Initialize Supplier Types

### שיטה 1: דרך mongosh (Command Line)
```bash
# התחבר למסד הנתונים והרץ את הסקריפט
mongosh videoprojectmanager init-supplier-types.js

# או העתק והדבק את התוכן ישירות ב-mongosh
mongosh videoprojectmanager
```

### שיטה 2: VS Code MongoDB Extension
1. פתח את הקובץ `init-supplier-types.mongodb`
2. לחץ על "Play" או Ctrl+Shift+P -> "MongoDB: Run Playground"

### שיטה 3: MongoDB Compass
1. פתח MongoDB Compass
2. התחבר למסד הנתונים `videoprojectmanager`
3. לך ל-Mongosh בתחתית
4. העתק והדבק את התוכן מ-`init-supplier-types.js`

### שיטה 4: אתחול אוטומטי דרך האפליקציה
הסקריפט גם רץ אוטומטית כאשר השרת מתחבר ל-MongoDB בפעם הראשונה.
